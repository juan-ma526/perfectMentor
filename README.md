# Perfect Mentor APP
# Development

Pasos para levantar la app de desarrollo

1. Entrar a la carpeta back y ejecutar el comando `npm install`
2. Entrar a la carpeta front/perfect-mentor-front y ejecutar el comando `npm install`
3. Entrar a MongoDB Atlas y crear una base de datos.
4. Crear un archivo .env y reemplazar la direccion que te da MongoDB Atlas en MONGO_URL
5. Reemplazar las variables de entorno
6. Entrar a la carpeta back y ejecutar el comando `npm run server` para levantar el backend.
7. Entrar a la carpeta front/perfect-mentor-front y ejecutar el comando `npm run dev` para levantar el frontend.
